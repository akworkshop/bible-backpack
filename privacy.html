1. 隱私權保護與承諾 (Privacy Policy)

Bible Backpack 是一套專為基督徒、團契與小組設計的純文字研經輔助工具。我們極度重視每位信徒的靈修隱私與個人資料安全：

  • 最少資料收集原則：我們僅透過 Google OAuth 獲取您的基本身分資訊（姓名、電子郵件、大頭貼頭像），用於識別您的登入身分與同步個人研經資料。
  • 純文字研經資料：您在系統中保存的研經筆記、靈修單張與自訂主題課程均加密存儲於 Supabase 雲端資料庫，僅供您本人帳號存取（透過嚴格的 Row Level Security 防護）。
  • API 金鑰安全：您所輸入的第三方 AI 金鑰（如 Google Gemini、Groq API Key）僅存儲於您的個人帳號設定中，絕不會轉售、外洩或用於任何商業推廣。
  • 無第三方廣告與追蹤：本應用程式絕不包含任何商業廣告追蹤代碼或第三方資料仲介分析工具。

2. 服務使用條款 (Terms of Service)

使用 Bible Backpack 即代表您同意本工具以「現狀 (As-Is)」提供非商業、個人靈修與團契小組研討之用：

  • 所有 AI 輔助生成之查經材料僅供輔助思考與小組討論啟發，不能取代聖經原文、正統歷史神學與教會牧者的牧養引導。
  • 使用者不得利用本系統進行任何違法、侵權或惡意濫用服務之行為。
