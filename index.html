1. Google Gemini API

官方首選 · 100% 免費

Google 官方提供，每日高達 1,500 次免費請求，系統內建 5 款模型自動平滑容錯。

開啟 Google AI Studio 官網 ↗
1

造訪 Google AI Studio 並登入

進入 aistudio.google.com/app/apikey，使用一般的 Google 帳號 (Gmail) 登入即可。首次登入若有條款提示，勾選同意即可。

2

點擊左側「Get API key」並建立金鑰

在畫面左上方或選單中點擊 「Get API key」，接著點擊藍色的 「Create API key」（在現有或新專案中建立）。

3

複製以 AIzaSy 開頭的金鑰字串

系統幾秒內會生成一串以 AIzaSy... 開頭的金鑰，點擊金鑰旁的「複製 (Copy)」圖示。

4

貼入 Bible Backpack 並測試連線

回到 Bible Backpack，點擊頂部「⚙️ 設定」，在 Google Gemini 欄位貼上金鑰，點擊「⚡ 測試連線」顯示綠色打勾後，按「儲存設定」即可開始研經！

2. Groq Cloud API

超極速 500t/s · 推薦通道

專為 LPU 晶片打造的推論引擎，1~2 秒生成全套經文研析，每日 14,400 次免費請求，完全不塞車。

開啟 Groq Console 官網 ↗
1

前往 console.groq.com 免費註冊

前往 console.groq.com/keys，使用 Google 帳號或 Email 註冊。完全不需要綁定信用卡，10 秒內即可完成驗證。

2

點擊「Create API Key」按鈕

在主畫面右上角或中上方點擊亮橘色或黑色的 「Create API Key」。

3

輸入金鑰名稱並按 Submit

在跳出的對話框中輸入識別名稱（例如：BibleBackpack），然後點擊 Submit 建立。

4

立即複製以 gsk_ 開頭的金鑰

⚠️ 特別注意：Groq 為了安全考量，金鑰只會在建立當下顯示一次！請務必立即點擊 「Copy」 複製。

5

貼入 Bible Backpack 並選擇模型

打開 Bible Backpack 設定 ➔ 選擇 Groq ➔ 貼上金鑰 ➔ 模型推薦選擇 llama-3.3-70b-versatile（旗艦 70B 神學深度考證）➔ 點擊測試連線並儲存！

1M 上下文 · 免費預覽

支援神秘強大模型 stealth/crouton-alpha，具備 1,000,000 Token 超大上下文，亦可自由切換百款模型。

開啟 OpenRouter 官網 ↗
1

造訪 openrouter.ai/keys 並登入

前往 openrouter.ai/keys，使用 Google、GitHub 或 Email 快速登入。

2

點擊「Create Key」建立金鑰

4. 本地離線 AI (Ollama / LM Studio)

100% 離線 · 免費開源 · 零依賴

將 AI 模型運行在自己電腦上，完全免連網、不花任何費用、研究紀錄絕對隱私。

下載 Ollama (官網) ↗
1

下載並安裝 Ollama

造訪 ollama.com 下載並完成安裝（支援 Windows、macOS 與 Linux）。

2

下載推薦研經模型

打開 Windows PowerShell 或 Mac Terminal，執行以下指令下載 Qwen 3.5 9B 模型（神學推理極其精準）：

ollama pull qwen3.5:9b
3

重要跨域 (CORS) 啟動配置

現代瀏覽器禁止網頁直接存取 localhost，請在啟動 Ollama 前設定 OLLAMA_ORIGINS="*"：

Windows PowerShell 指令：
$env:OLLAMA_ORIGINS="*" ; ollama serve
Mac / Linux Terminal 指令：
OLLAMA_ORIGINS="*" ollama serve
4

回到 Bible Backpack 一鍵測試與自動偵測

在設定中選擇 本地離線 AI ➔ 點擊「💻 測試連線」，系統會自動探測您本機安裝好的全部模型，選取後即可開始 100% 離線研經！

PowerShell / Terminal 運行示意

✅ 成功連線！系統將啟用 think: false 極速模式，跳過冗長思考鏈，直接極速輸出排版漂亮的雙層靈修卡。

無伺服器中繼 (Zero Server Intercept)

所有 AI 請求都是由您的瀏覽器端直接向 Google、Groq、OpenRouter 或本地 Ollama 發出。Bible Backpack 的網頁主機絕不中繼、絕不記錄您的私密 API Key。
